# 🏨 Vista Resort Dashboard

## 📊 Project Overview

**Vista Resort Dashboard** is an interactive **Power BI dashboard** created to analyze hotel and resort management data.

The dashboard provides insights into **bookings, rooms, occupancy, revenue, payments, customers, and employees**.

---

## 🛠️ Tools Used

* **Power BI** – Dashboard and data visualization
* **Microsoft Excel** – Data cleaning and preparation
* **Python / Pandas** – Data processing and analysis
* **CSV** – Dataset storage

---

## 📑 Dashboard Pages

### 1. Executive Overview

Provides an overall view of resort performance.

**KPIs:**

* Total Bookings
* Occupancy Rate
* Total Customers
* Available Rooms
* Pending Payment
* Total Revenue

---

### 2. Booking Analysis

This page analyzes booking performance.

**Includes:**

* Booking trends
* Booking status
* Customer activity
* Stay duration
* Monthly booking analysis

---

### 3. Room Analysis

This page provides information about the resort's rooms.

**Includes:**

* Room types
* Room count
* Average room price
* Average capacity
* Room availability
* Room status
* View type
* Bed type

**Total Rooms: 84**

---

### 4. Payment Analysis

This page analyzes payment information.

**Includes:**

* Payment amount
* Payment status
* Payment methods
* Amount paid
* Remaining amount
* Pending payments

**Payment Methods:**

* UPI
* Debit Card
* Credit Card
* Cash
* Net Banking

---

### 5. Employee Analysis

This page provides employee-related booking information.

**Includes:**

* Employee-wise booking activity
* Booking distribution
* Employee-related booking analysis
